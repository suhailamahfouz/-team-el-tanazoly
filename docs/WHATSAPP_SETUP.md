# واتساب Click-to-Chat اليدوي

النظام لا يستخدم WhatsApp API أو Webhooks أو إرسالًا تلقائيًا. من لوحة الحجوزات يختار الأدمن رقم العميل أو رقم التجديد، ويراجع/يعدّل نص الرسالة، ثم يفتح محادثة Click-to-Chat.

## الإعداد والاستخدام

1. من لوحة الإدارة ← الإعدادات، أضيفي رقم واتساب للنشاط بصيغة مصرية أو دولية.
2. عند فتح طلب، اختاري «رقم العميل» أو «رقم التجديد».
3. يمكن تعديل الرسالة قبل فتح واتساب أو كتابة رسالة مخصصة.
4. يسجّل النظام فتح واتساب ووقت الفتح فقط. بعد إرسال الرسالة يدويًا، اضغطي «تأكيد الإرسال يدويًا» لتسجيل التأكيد والموظف والتاريخ.

## قالب مقترح لرسالة التجديد

أهلاً يا {{customer_name}} ❤️

تم تجديد باقتك بنجاح 🎉

📦 الباقة: {{package_name}}
📱 الرقم: {{renewal_phone}}
💰 السعر: {{price}} جنيه

شكراً لثقتك في تيم النزلاوي 👑

**فتح رابط واتساب لا يعني أن الرسالة أُرسلت.** لا يسجل النظام أنها أُرسلت إلا بعد التأكيد اليدوي من الأدمن.
